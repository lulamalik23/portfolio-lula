02 — TENTANG PROYEK

Tentang Proyek

Hand Gesture Recognition merupakan proyek Python yang dikembangkan untuk mempelajari cara mendeteksi gerakan tangan menggunakan kamera. Proyek ini memanfaatkan teknologi computer vision untuk memproses gambar dan mengeksplorasi keluaran suara berdasarkan gerakan yang dikenali.

Tujuan proyek ini adalah mengeksplorasi alternatif interaksi dengan komputer melalui gerakan tangan menggunakan teknologi berbasis Python.

03 — TEKNOLOGI

Teknologi yang Digunakan

Python

Bahasa pemrograman utama yang digunakan untuk mengembangkan proyek.

OpenCV

Digunakan untuk mengakses kamera dan memproses gambar yang ditangkap.

MediaPipe

Digunakan untuk mempelajari deteksi titik tangan dan pelacakan gerakan tangan.

gTTS & Pygame

Digunakan untuk mengeksplorasi pembuatan suara dari teks dan pemutaran audio.
